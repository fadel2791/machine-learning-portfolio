01 / OVERVIEW

Tentang Praktikum

Praktikum ini membahas penerapan algoritma Simple Linear Regression untuk menganalisis hubungan antara biaya iklan dengan jumlah penjualan produk.

Simulasi menggunakan dataset buatan yang menggambarkan hubungan biaya iklan dengan penjualan. Model digunakan untuk mempelajari pola hubungan dan melakukan prediksi.

02 / DATASET

Variabel Penelitian

X — Independent Variable

Biaya Iklan

Jumlah biaya iklan dalam ribuan rupiah.

Y — Dependent Variable

Penjualan

Jumlah produk yang berhasil terjual dalam unit.

Tahapan Praktikum

  1. Mempersiapkan dataset penjualan produk.
  2. Melakukan eksplorasi dan statistik deskriptif.

  4. Membangun model Simple Linear Regression.
  5. Menghitung intercept dan koefisien regresi.
  6. Melakukan simulasi prediksi penjualan.
