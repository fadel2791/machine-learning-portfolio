Prediksi konsumsi listrik rumah tangga berdasarkan jumlah penghuni, penggunaan AC, dan perangkat elektronik.

Python Pandas Scikit-learn
01 / OVERVIEW

Tentang Praktikum

Praktikum ini membahas penerapan Multiple Linear Regression untuk memprediksi konsumsi listrik rumah tangga berdasarkan beberapa variabel independen.

Dataset menggunakan simulasi kondisi rumah tangga untuk mempelajari hubungan beberapa faktor terhadap konsumsi energi listrik.

02 / DATASET

Variabel Penelitian

X1 — Independent Variable

Jumlah Penghuni

Jumlah orang yang tinggal dalam rumah.

X2 — Independent Variable

Penggunaan AC

Durasi penggunaan AC per hari.

X3 — Independent Variable

Penggunaan Elektronik

Durasi penggunaan perangkat elektronik.

Y — Dependent Variable

Konsumsi Listrik

Jumlah konsumsi listrik bulanan dalam kWh.

03 / METHODOLOGY

Tahapan Praktikum

  1. Mempersiapkan dataset konsumsi listrik.
  2. Melakukan statistik deskriptif.

  4. Membuat visualisasi dan matriks korelasi.
  5. Membangun model Multiple Linear Regression.
  6. Melakukan simulasi prediksi konsumsi listrik.
